PNG transparent : définition et création

Un « fond transparent » n'est ni blanc ni un damier : c'est une absence de pixels. Voici comment ça marche et les pièges à éviter.

La transparence dans une image

Chaque pixel a trois valeurs de couleur (rouge, vert, bleu). Certains formats ajoutent une quatrième valeur, le canal alpha, qui indique l'opacité du pixel : 0 invisible, 255 totalement visible, et toutes les valeurs intermédiaires pour du semi-transparent. Un bon détourage utilise ces valeurs sur les bords, pour que les cheveux ou les ombres douces se fondent dans n'importe quel nouveau fond.

Les formats

  • PNG : transparence complète, sans perte. Le choix sûr pour logos, stickers et détourages.
  • WEBP : transparence avec des fichiers bien plus légers. Idéal pour le web, moins reconnu par les vieux logiciels.
  • JPG : aucune transparence. Une zone transparente devient une couleur unie (souvent blanc ou noir).
  • GIF : transparence tout ou rien, bords crénelés. À éviter pour les photos.

Créer un PNG transparent

  1. Ouvrez votre image dans Poppix : le fond est retiré automatiquement.
  2. Dans l'onglet Fond, gardez la pastille en damier : elle signifie « transparent ».
  3. Cliquez sur Télécharger et choisissez PNG (ou WEBP).

Le piège du faux damier

Beaucoup d'images trouvées en ligne affichent un damier gris et blanc sans être transparentes : le damier est imprimé dans les pixels. On le repère aux carreaux légèrement ondulés ou flous. Posée sur un fond coloré, l'image laisse apparaître le damier. La solution : la détourer à nouveau, comme n'importe quel fond.

Garder la transparence

  • Certaines messageries convertissent les images en JPG et remplacent la transparence par du noir ou du blanc. Envoyez le fichier en tant que document.
  • Si vous retouchez le PNG dans un autre logiciel, réexportez-le en PNG.
  • Vérifiez le résultat sur un fond sombre et sur un fond clair.
