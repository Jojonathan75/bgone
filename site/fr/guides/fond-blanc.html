Photos sur fond blanc pour les marketplaces

Beaucoup de marketplaces demandent un fond blanc uni pour l'image principale. Ça paraît simple, mais quelques détails font la différence entre une fiche professionnelle et une image refusée.

Pourquoi le blanc ?

Le fond blanc met tous les produits à égalité dans les résultats de recherche, supprime les distractions et permet de bien juger les couleurs.

Exigences courantes

Les règles varient selon les plateformes et évoluent : vérifiez toujours les consignes actuelles de la vôtre. Pour l'image principale, on attend en général :

  • un fond blanc pur, souvent précisé en RVB 255, 255, 255 ; un blanc cassé ou un gris clair peut être signalé ;
  • un produit qui occupe l'essentiel du cadre, avec une petite marge ;
  • pas de texte, logo, filigrane, bordure ni accessoire non vendu ;
  • une taille minimale, souvent autour de 1000 pixels sur le grand côté, pour permettre le zoom.

Pas à pas

  1. Ouvrez votre photo dans Poppix et laissez-le retirer le fond.
  2. Corrigez les ombres restantes ou les parties manquantes dans l'onglet Retoucher.
  3. Dans l'onglet Fond, choisissez la pastille blanche : c'est un blanc pur.
  4. Ajoutez éventuellement une légère ombre portée.
  5. Téléchargez en JPG avec Recadrer sur le sujet.

Erreurs à éviter

  • Liserés : un fin contour sombre se voit beaucoup sur du blanc. Rétrécissez le contour d'un pixel.
  • Le « blanc » gris : photographier sur une feuille blanche ne suffit pas, elle ressort toujours grise. Remplacer le fond garantit un vrai blanc.
  • Trop de retouche : ne modifiez pas les couleurs du produit pour le rendre plus flatteur ; les retours viennent souvent de produits différents de leur photo.
