    Pertanyaan umum

    Apakah kualitas gambar saya akan turun?

    Kompresi menghapus detail yang nyaris tidak terlihat oleh mata. Pada kualitas 75 sampai 85, perbedaannya biasanya tidak terlihat, sementara file sering 50 sampai 80% lebih ringan. Gunakan tombol Bandingkan untuk memeriksa sebelum mengunduh.

    Format apa yang sebaiknya dipilih?

    WEBP adalah pilihan terbaik untuk situs web dan didukung semua browser modern. AVIF lebih ringan lagi, tetapi lebih lama dibuat dan tidak semua aplikasi menerimanya. JPG bisa dipakai di mana saja, termasuk email dan cetak. PNG cocok untuk logo, tangkapan layar, dan gambar transparan.

    Apakah gambar saya diunggah ke server?

    Tidak. Kompresi berjalan di browser, di perangkat Anda. Gambar Anda tidak pernah dikirim atau disimpan.

    Apakah ada batas ukuran atau jumlah file?

    Tidak ada selain memori perangkat Anda. Gambar yang sangat besar (lebih dari 50 megapiksel) bisa lambat di ponsel.
