    Pertanyaan umum

    Seberapa kecil PDF saya nanti?

    Tergantung isinya. PDF yang penuh foto atau halaman pindaian sering berkurang 70 sampai 95%. PDF yang hanya berisi teks (misalnya diekspor dari Word) sudah ringkas: perkirakan 0 sampai 50%, kadang tidak berkurang sama sekali. Jika hasilnya tidak lebih kecil, Anda mendapatkan kembali file aslinya.

    Apakah teks tetap bisa dipilih?

    Ya, pada tingkat Ringan, Disarankan, dan Kuat: hanya gambar yang dikompres ulang. Hanya mode Halaman jadi gambar yang mengubah setiap halaman menjadi gambar.

    Apakah file saya diunggah ke server?

    Tidak. Kompresi berjalan di browser dengan mesin sumber terbuka Ghostscript. Dokumen Anda tidak pernah meninggalkan perangkat.

    Bisakah saya mengompres PDF yang dilindungi kata sandi?

    Tidak. Buka dengan kata sandinya, simpan salinan tanpa perlindungan terlebih dahulu, lalu kompres salinan itu.
